# ax2r core swap — 2 × `hexcel_uni_231` → 1 × `hexcel_uni_379`

**Question.** ax2r's FULL-zone spanwise core is a mirrored pair of
`hexcel_uni_231` plies (ax2r.csv plies 5 & 6, 0°, 0.2541 mm each). What does the
blade do if that pair is replaced by a single ply of the ~2×-heavier roll,
`hexcel_uni_379` (0°, 0.4169 mm)?

**Layup:** `ax/ax2r_379.csv` (7 plies; structure = `ax2r1.csv` with the heavier
core ply). Worksheet with ply-stack diagrams, deformed-blade side views and cut
sheets: `ax2r_379_report.html`.

Bench: `cases/fin_test_3` tip-weight buckling cantilever, `FIN_TEST_3.step`,
`--uy-frac 0.60 --bow-tip-mm 0.5 --kick-bands 41 --twist-probe`, materials
`materials/from_shop.csv`. `ax2r1` is carried as a reference point — it is the
same swap taken all the way to a single *thin* (231) core ply.

## Read

1. **Flex −30 %.** The swap removes 0.091 mm of 0° core (0.508 → 0.417 mm) over
   the whole FULL zone. Open-blade `D11` falls to 0.67× and flex tracks it
   (10.85 → 7.55 N, 0.70×). `hexcel_uni_379` reuses the `hexcel_uni_231` IM2
   lamina card, so stiffness *per unit thickness* is unchanged — this is purely
   a section-thickness / `t³` effect. The single fat 379 ply holds far more
   than a single thin 231 ply: it recovers ~55 % of the flex that going to one
   231 ply (`ax2r1`, 3.56 N) gives up.
2. **Kick unchanged.** MID, `f` = 0.451 → 0.451 → 0.453, migration −2.1 → −2.3 →
   −2.4 mm — no resolvable change at 41 bands (station spacing ~16 mm). The
   change is uniform on FULL, so the QUARTER/MID stiffness taper that sets the
   fold location is untouched. Flex and kick stay separable, as
   `design-levers.md` predicts for a FULL-only move.
3. **Tip twist −20 %.** k_twist 18992 → 15198 at matched θ. The ±45 twill skins
   that carry torsion are unchanged, but the section is thinner, so `D66`/`GJ`
   drop. This is a real cost alongside the flex loss — the fat ply does **not**
   buy twist stiffness back (still well above `ax2r1`'s 0.50×, though).
4. **Warp / B.** Open blade and MID band are **exactly B = 0**: `uni_379` and
   `uni_231` share the card, so the 0° block is stiffness-uniform and stays
   centred between the ±45 skins. Only the root picks up a residual,
   B/√(A11·D11) = 0.018 — under the 0.03 "cures flat" line, ~a quarter of
   `ax2r1`'s 0.068 — because ax2r's fully interleaved `[45/0/0/45/0/0/45]` root
   loses one mid-stack 0° and becomes `[45/0/0/45/0/45]`. The `[45/0/45/45]`
   TIP-zone residual is essentially unchanged (0.259 → 0.267) and is the
   pre-existing accepted one. **D16 = 0 in every stack** — expected for this
   all-0°/balanced-±45 family and required, but note this family cannot detect a
   mirrored `*ORIENTATION` (it agrees at 0/±45/90°), so it is not by itself
   evidence for the sign convention.
5. **Mass / labour.** One fewer full-blade ply: dry laminate ~248 → ~229 g
   (−8 %), one fewer full-planform ply to cut, place and debulk. That is the
   upside the swap buys.

## Verdict

Replacing ax2r's mirrored 231 core pair with one 379 ply gives a **~3.3 N
softer blade (10.9 → 7.6 N) that is still a clean MID-kick laminate, B ≈ 0 in
every load-bearing zone (the TIP pad keeps its pre-existing ~0.26), D16 = 0**,
at ~8 % less mass and one fewer ply — for a **~20 % loss of tip-twist stiffness
(0.80×)**. It is **not** a like-for-like substitution: 2 × 0.2541 ≠ 1 × 0.4169
mm (−18 % core), so `ax2r_379` lands as a distinct softer design *between* ax2r
and ax2r1, not a drop-in for ax2r. Worth it if a ~7–8 N super-soft with a MID
kick is the goal and the twist hit is acceptable; keep the pair if ax2r's flex
and twist are the target.

## Caveats

- Absolute newtons move with the non-final `FIN_TEST_3.step` (`EI ~ t³ ~ L³`).
  The **−30 % flex** and **0.80× twist** ratios are the deliverable, not 7.55 N.
- `hexcel_uni_379`'s lamina card is the `hexcel_uni_231` card reused pending a
  datasheet, so any real IM2-379 modulus / Vf difference is not modelled. If a
  datasheet lands, re-author the card through `materials.py` and re-solve.
- Single (developable) curvature only; no cure-stress model — hence the B check
  is the only warp warning available.

## Reproduce

```sh
# ABD cross-check (seconds, no solver)
python -m compfea.build --step FIN_TEST_3.step --long-axis y \
    --plybook cases/fin_test_3/ax/ax2r_379.csv --materials materials/from_shop.csv --out /tmp/abd

# solve (~2 min each; launch detached, poll the run dir)
for n in ax2r ax2r_379 ax2r1; do
  python cases/fin_test_3/run_tipweight.py --plybook cases/fin_test_3/ax/$n.csv \
      --materials materials/from_shop.csv --uy-frac 0.60 --bow-tip-mm 0.5 \
      --kick-bands 41 --twist-probe --run-dir results/ax2r_379study/$n
done

python .claude/skills/fin-layup-design/scripts/report.py \
    --baseline results/ax2r_379study/ax2r --plybook-dir cases/fin_test_3/ax \
    --out cases/fin_test_3/ax2r_379_report.html \
    results/ax2r_379study/ax2r_379 results/ax2r_379study/ax2r1
```
